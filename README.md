# Thiago Meireles | Portfólio Acadêmico & Blog

Bem-vindo ao repositório do meu site pessoal e profissional. Este projeto hospeda meu portfólio, pesquisas, currículo e notas técnicas sobre Data Science e programação.

🔗 **Acesse o site:** [thiagomeireles.com.br](https://thiagomeireles.com.br)

---

## 🛠 Sobre o Projeto

Este site foi construído seguindo a filosofia de **"infraestrutura como código"** e simplicidade. A ideia central é ter uma plataforma leve, gratuita e fácil de manter, permitindo foco total no conteúdo acadêmico e técnico.

### Stack Tecnológica
* **Gerador Estático:** [Jekyll](https://jekyllrb.com/)
* **Hospedagem:** GitHub Pages
* **Linguagem:** Markdown (conteúdo) + HTML/CSS (customizações)
* **IDE & Gestão:** [Positron](https://github.com/posit-dev/positron) (by Posit)
* **Formulários:** [Tally](https://tally.so)

---

## 🚀 Fluxo de Trabalho (Positron)

Diferente do fluxo tradicional de desenvolvimento web, todo este site é gerenciado através do **Positron**. A nova IDE da Posit permite integrar a escrita técnica (Markdown), o controle de versão (Git) e a gestão de arquivos em uma única interface familiar para Cientistas de Dados.

> **Curiosidade:** Embora seja um site web, o fluxo de manutenção é muito similar ao de um projeto de análise de dados em R.

---

## 📂 Estrutura do Repositório

Para quem tem curiosidade de entender como um site Jekyll funciona "por baixo do capô", aqui está o mapa dos arquivos principais:

* `_config.yml`: O "cérebro" do site. Arquivo YAML que contém todas as configurações globais e do tema.
* `_posts/`: Onde residem os artigos do blog. Cada arquivo é um Markdown datado.
* `en/`: Pasta dedicada à versão em inglês do site.
* `assets/`: Imagens e arquivos estáticos.
* `cv.md` / `sobre.md`: Páginas estáticas principais.

---

## 🎨 Customizações (Além do Markdown)

Embora o tema base resolva 90% da estrutura, utilizei **HTML e CSS** para funcionalidades específicas de um portfólio de pesquisador, superando as limitações do Markdown puro:

1.  **PDF Embed:** Uso de tags `<embed>` e `<object>` para visualizar PDFs diretamente no navegador.
2.  **Mídia Responsiva:** Integração de vídeos via iFrames ajustados.
3.  **Interatividade:** Formulários de contato integrados via **Tally**, eliminando a necessidade de backend.
4.  **Estilo:** CSS personalizado para refinar a tipografia e layout.
